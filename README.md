🛒 Blinkit Clone

A responsive front-end clone of the Blinkit grocery delivery website, built with HTML and Tailwind CSS to practice e-commerce UI design.

🔗 Live Demo: https://blinkit-clone-u8gb.vercel.app/

> **Note:** This is a student demo project for UI practice. It is not the official Blinkit website and does not process orders.

✨ Features
- Header with navigation (Home, Shop, Offers, Contact), search bar and cart icon
- Hero banner: "Get Groceries Delivered in Minutes"
- Shop by Category section (Fruits & Vegetables, Dairy, Bakery, Beverages)
- Featured Products grid with price and "Buy Now" button
- Dairy Products grid
- Footer with disclaimer and contact details

 🛠️ Built With
- HTML5
- Tailwind CSS (via CDN)
- Font Awesome icons
- Google Fonts (Roboto)
- Deployed on Vercel

🚀 Run Locally
```bash
git clone https://github.com/AlizaParveen/Blinkit-clone.git
cd Blinkit-clone
# open index.html in your browser
```

📌 Current Status
This is a static front-end only. The search bar, cart icon and "Buy Now" buttons are UI elements and are not functional yet.
